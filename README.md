# 성경 발자국

말씀의 땅을 오늘의 지도 위에서. 전 성도가 함께 보는 성경 지도.

## 여는 방법
- 이 폴더를 그대로 GitHub Pages에 올리면 웹사이트가 됩니다 (서버 필요 없음).
- 파일: index.html(화면), journeys.js(여정·지명 데이터), basemap.js(지도 바탕), leaflet.js / leaflet.css(지도 엔진)

## 여정·지명 고치기
journeys.js 하나만 고치면 됩니다. 장소마다 name(개역개정 지명), now(지금 이곳), lat/lng(위도/경도), ref(성경 구절), desc(설명), guess(위치 추정)가 있습니다.

## 자료 출처
- 지도 바탕: Natural Earth (퍼블릭 도메인), world-atlas
- 위성사진: Esri World Imagery (인터넷 연결 시)
- 지도 엔진: Leaflet (BSD-2 라이선스)
